# Grafana

## Objetivo

Oferecer painéis e exploração visual para métricas, traces e logs da plataforma.

## Responsabilidades

- Criar painéis de saúde e desempenho dos serviços.
- Configurar alertas para condições operacionais relevantes.
- Organizar fontes de dados e permissões por equipe.

## Integração

Conectar fontes de dados compatíveis com os sinais exportados por OpenTelemetry e pela infraestrutura. Versionar dashboards e regras de alerta como configuração reproduzível, evitando credenciais nos arquivos.
