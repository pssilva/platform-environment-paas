- [OpenTelemetry](./opentelemetry/README.md)

- [Aplicação Backend RESTful](./backend-restful/README.md)
- [Aplicações Frontend (Angular e React)](./frontend-angular-react/README.md)

Cada pasta documenta a finalidade do componente, seu papel na plataforma e pontos de integração. Este repositório começa como estrutura documental e pode evoluir para manifests, configurações e código executável.
