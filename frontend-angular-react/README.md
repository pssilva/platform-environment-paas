# Aplicações Frontend: Angular e React

## Objetivo

Documentar os frontends de referência da plataforma: uma aplicação Angular e uma aplicação React. Cada aplicação pode evoluir em seu próprio repositório ou subprojeto.

## Diretrizes

- Consumir a API do backend por uma URL configurável por ambiente.
- Manter validação de acessibilidade, build e verificações de dependências no CI.
- Não incluir segredos no código entregue ao navegador.
- Instrumentar erros e desempenho com cuidado para não coletar dados sensíveis.

## Entrega

Jenkins pode executar pipelines independentes para Angular e React, com análise SonarQube e publicação de artefatos estáticos. Documente comandos, variáveis públicas de build e processo de implantação de cada aplicação.
