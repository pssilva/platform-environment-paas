# Aplicação Backend RESTful

## Objetivo

Serviço de exemplo que expõe recursos por uma API HTTP RESTful e integra-se ao PostgreSQL.

## Diretrizes

- Documentar endpoints, modelos e códigos de resposta.
- Validar entradas e aplicar autenticação e autorização conforme necessário.
- Gerenciar mudanças de esquema com migrações versionadas.
- Configurar dependências e segredos por ambiente.
- Instrumentar traces, métricas e logs com OpenTelemetry.

## Entrega

O código deve incluir instruções de execução local e configuração, além de pipeline Jenkins para build, verificações de qualidade no SonarQube e publicação do artefato.
